# Como Contribuir

## 🐛 Reportar Bugs

Abra uma Issue com:
- Título descritivo
- Passos para reproduzir
- Comportamento esperado vs obtido
- Versão do PHP/MySQL

## 💡 Sugerir Melhorias

Abra uma Issue com tag enhancement.

## 🔧 Enviar Código

1. Fork o projeto
2. Crie uma branch: git checkout -b feat/minha-feature
3. Commit: feat: adiciona funcionalidade X
4. Pull Request

### Padrões
- PHP: PSR-12
- Commits: Conventional Commits
- Sem warnings do PHP
- Documentação atualizada
